# Power-BI-Project-1

Power BI Sales Performance Dashboard (Q1 2025)
Project Overview
This project analyses sales performance for Q1 2025 using an interactive Power BI dashboard.
The objective is to provide a clear overview of revenue trends, product performance, and store-level sales insights to support data-driven business decisions.


⸻


Key Business Questions
The dashboard answers the following questions:
1. What was the total revenue generated in Q1 2025?
2. Which product category generated the highest revenue?
3. Which store sold the highest number of units?
4. What were the top 3 best-selling products by units sold?
5. How did monthly revenue trend across the quarter?

   
⸻


Key Insights

• Total revenue for Q1 2025: £785,365

• Top revenue category: Laptops (£330,700), indicating strong demand for high-value products

• Top performing store: Store B, with the highest total units sold (445 units)

• Best-selling products:

1. Galaxy Tab – 149 units
2. Charger – 136 units
3. Samsung S23 – 130 units
• Revenue trend: Revenue peaked in February (£347,780) before declining in March, while remaining higher than January overall
